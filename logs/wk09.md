## Code I'm proud of (optional)
def count_bigram(bigram):
    key = tuple(bigram)
    if key not in bigram_counter:
        bigram_counter[key] = 1
    else:
        bigram_counter[key] += 1

I am most proud of this section of code because it uses a tuple as a dict key to count how many times each pair of words appears together. This is the first step to build a Markov text generator.
