## What I learned this week
This week I finished both of my elective mini projects. The first one is the Monty Hall Simulator, which simulates the classic probability puzzle thousands of times to see if switching doors really wins more than staying. I learned how to use the random module to simulate a game round, how to split the code into separate functions for one round vs many rounds, and how to use matplotlib to make a bar chart and a convergence line chart. The empirical results matched the theoretical 1/3 vs 2/3 almost exactly, which was very satisfying to see. The second project is Terminal Wordle, a command line clone of the Wordle game. I learned how to use ANSI escape codes to add color to the terminal, how to validate input when the user types something that is not 5 letters or not in the word list, and how to track game state across multiple rounds for the session statistics. I also learned that the scoring logic for duplicate letters is trickier than I thought, because each letter in the answer can only be matched once.

## Code I'm proud of (optional)
def play_round(strategy):
    car = random.randint(0, 2)
    pick = random.randint(0, 2)
    host_opens = next(i for i in range(3) if i != pick and i != car)
    if strategy == "switch":
        pick = next(i for i in range(3) if i != pick and i != host_opens)
    return pick == car

I am most proud of this section of code because it captures the whole Monty Hall game in just a few lines. Once I had this function working, everything else was just calling it many times and counting the wins.

## Challenges I faced
The hardest part was the Wordle color rendering. The first time I ran my code, all the letters showed up as plain text with no color at all, even though my terminal supports ANSI colors. I had to test the colors separately in the terminal first to confirm it was a code bug and not a terminal bug. The duplicate letter scoring in Wordle was also confusing at first. For example if the answer is APPLE and I guess PAPER, only the second P should be green and the first P should be yellow, not both yellow. I learned that I have to do two passes through the letters, first finding the greens and then the yellows.
