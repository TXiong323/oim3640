## Code I'm proud of (optional)
def md5_digest(filename):
    data = open(filename, 'rb').read()
    md5_hash = hashlib.md5()
    md5_hash.update(data)
    return md5_hash.hexdigest()

I am most proud of this section of code because it turns any file into a short string, and two files with the same contents will get the same digest. This makes it possible to find duplicate photos without comparing every pair of files one by one.
