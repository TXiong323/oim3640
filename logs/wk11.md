## Code I'm proud of (optional)
@app.route('/search', methods=['POST'])
def search():
    place = request.form['place']
    return render_template('result.html', place=place)

I am most proud of this section of code because it connects everything together. The user types something into an HTML form, Flask catches the POST request, pulls the value out of request.form, and then passes it into a template to render a new page. It is a small piece of code but it actually makes a real web app work.
