## My Project Proposal

**What I'm building:** A command-line account book where I can log 
purchases and review my spending by week or month
**Why I chose this:** I want to track where my money is actually going 
after I shop, so I can look back and understand my spending habits
**Core features:** 
- Log an expense: enter an item name, price, and date
- View all expenses in a clean list
- See a weekly spending summary
- See a monthly spending summary
- Quit cleanly with a menu
**What I don't know yet:**
- How to work with dates in Python=
- How to filter expenses by week or month
- How to save expenses so they don't disappear when the program closes
- How to handle bad input
